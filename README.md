# SE-Group17-2026

A conversational application of a historical figure.

## Start the frontend

Install [Node.js and npm](https://nodejs.org/) if you do not already have them. From the project folder, run:

```bash
cd front
npm install
npm run dev
```

Open the local address shown in the terminal (usually http://localhost:5173/). Press `Ctrl+C` in the terminal to stop the development server.
